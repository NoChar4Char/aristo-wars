How to Play

Each puzzle is a famous quotation. Every letter has been swapped for a different letter, and the same swap is used all the way through. If X stands for E once, it stands for E everywhere.

  • Click a letter and type your guess. Every copy of that code letter fills in at once.
  • Backspace, Delete or Space clears a letter. Use the arrow keys to move around.
  • Letters Remaining shows which answer letters you haven't used yet.
  • Tick Show letter frequencies to see how often each code letter appears. E, T, A and O are the most common letters in English.
  • You get 3 hints per puzzle. Each hint reveals one letter but freezes your board for 10 seconds.

In a duel, both players get the same cipher. You can see how far along your rival is, but not their letters. Whoever solves it first wins the round.
