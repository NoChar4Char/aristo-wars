How to Play

Each puzzle is a famous quote where every letter has been swapped for another letter. The same swap is used all the way through, so if X means E once, it means E everywhere.

  • Click a box and type a letter. Every box with the same code letter fills in at once.
  • Backspace, Delete or Space clears a letter. The arrow keys move you around.
  • Letters Remaining shows which answer letters you haven't used yet.
  • The Letter Frequency table under the puzzle shows how often each code letter appears. Tip: E, T, A, O are the most common letters in English!
  • Hints: either player can propose one at any time. If your rival agrees, one letter is revealed on both boards.

You'll both get the exact same cipher. You can watch your rival's progress bar, but not their letters.
