How to Play

Each puzzle is a famous quote where every letter has been swapped for another letter. The same swap is used all the way through, so if X means E once, it means E everywhere.

  • Click a box and type a letter. Every box with the same code letter fills in at once.
  • Backspace, Delete or Space clears a letter. The arrow keys move you around.
  • Letters Remaining shows which answer letters you haven't used yet.
  • The Letter Frequency table under the puzzle shows how often each code letter appears, and the letter you've put for it. Compare it with the Frequency Table of English Letters. E, T, A, O are the most common!
  • On Default Settings you can turn off autofill (so each box fills on its own), matching-letter highlights, the Letters Remaining panel or the letter table, and choose uppercase or lowercase letters.
  • Hints: any player can propose one. If enough others agree (the host decides how many), one letter is revealed on everyone's board.

Everyone gets the exact same cipher. You can watch the other players' progress bars, but not their letters.

Scoring

Solving a puzzle is worth 100 points. If the round ends before you finish, you still get partial credit: you lose a set number of points for every unfinished letter beyond an allowance the host picks. A round ends when everyone is done, when the time limit runs out, or when the grace period after the first solve is over. The highest total after the last round wins.

Getting a game going
  1. On Play Online, pick a name and click Set Up a Room.
  2. Choose the rules, or click Use My Defaults (you set those on Default Settings).
  3. Send your friends the room code or the link. Up to 6 players can join.
  4. Click Start Match when everyone's in.
